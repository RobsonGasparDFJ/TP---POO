# Sistema de Gerenciamento de Banco
Projeto de um sistema bancário em Java, desenvolvido na disciplina de Programação Orientada a Objetos. Usa os conceitos vistos em aula (classes, herança, encapsulamento, etc.) e tem interface web e banco de dados.

# Tecnologias
- Java
- Interface web (HTML, CSS e JS)
- SQL
