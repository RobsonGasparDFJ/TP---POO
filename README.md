## 📖 Introdução

Este projeto consiste em um **Sistema Bancário Digital** desenvolvido para aplicar na prática os conceitos estudados na disciplina de Programação Orientada a Objetos (POO). O sistema integra funcionalidades diversas, como login e transferências.

---

## ⚙️ Funcionalidades

| 🧩 Funcionalidade | 📝 Descrição |
|---|---|
| 🔐 **Autenticação de Usuários (Login)** | É a porta de entrada do sistema, responsável por garantir a segurança e a privacidade das contas. |
| 👤 **Gerenciamento de Perfil (Editar perfil)** | Consulta e atualização de informações do perfil do usuário. |
| 💸 **Operações Financeiras (Transações)** | Núcleo operacional do sistema bancário, responsável por movimentar recursos entre contas. |
| 🧾 **Extrato Bancário (Visualizar extrato)** | Consulta detalhada sobre todas as movimentações financeiras realizadas pelo usuário. |
| 📊 **Análise Financeira (Dashboard e relatórios)** | Painel visual e intuitivo que ajuda o usuário a compreender e acompanhar seus gastos financeiros. |
